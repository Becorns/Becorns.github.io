# 小程序抓包

## 环境准备

- Windows / macOS 均可
- 安装 Charles，手机与电脑处于同一局域网

## 配置代理

1. 打开 Charles → `Proxy` → `Proxy Settings`，开启 HTTP 代理，默认端口 8888
2. 手机 Wi-Fi 设置代理为电脑 IP + 8888

## 证书安装

HTTPS 流量需要安装 Charles 根证书：

1. 电脑端：`Help` → `SSL Proxying` → `Install Charles Root Certificate`
2. 手机端：访问 `chls.pro/ssl` 下载并安装证书
3. 开启 `SSL Proxying`，添加域名 `*` 或具体域名

## 常见问题

| 问题 | 解决 |
| ---- | ---- |
| 显示乱码 | 开启 `SSL Proxying` |
| 小程序不走代理 | 检查是否开启系统代理 |
| 证书无效 | 重新安装并信任证书 |

## 小结

抓包是排查小程序接口问题的利器，注意只用于调试自己的服务。
