### .htaccess

(分布式配置文件)。可以包含entry格式的配置指令，也可以有配置容器：<...></..>,类似if语句，满足容器条件，就执行容器内部的

> 覆盖所管理的目录配置
> **原理**：本质就是利用apache根据配置文件(配置容器)把传入的数据进行分拣，交给不同的处理器。
> 比如php 就交给 application/x-httpd-php。利用目录级别的htaccess将默认分拣配置给覆盖掉。实现错误的分拣。
> **前提**：目标用的是Apache， httpd.conf：**AllowOverried ALL**

| 处理器                    | 说明         | eg                                       |
| ---------------------- | ---------- | ---------------------------------------- |
| aplication/x-httpd-php | php处理器     | SetHandler application/x-httpd-php       |
| php-script             | cig模式下的php | SetHandler "proxy:fcgi://127.0.0.1:9000" |
| php5-script            |            |                                          |

* SetHandler

     > Handler(处理器)，SetHandler:设置处理器
     > 强制将所有文件交给application/x-httpd-php处理器处理。
     > 或者在处理器后面加上文件后缀，强制将这类文件当作php

     ```htaccess
     #mime是apache的一个模块，这个模块默认是加载的，所以没有ifModule也可以执行模块里工具。但是为了稳定，还是加上
     <IfModule mime_module> #判断是否加载了模块
     	SetHandler application/x-httpd-php    #所有请求都交给php
     	SetHandler application/x-httpd-php .jpg   #指定.jpg文件交给php处理
     </IfModule>
     ```

* AddHandler

     > 和SetHandler类似，一样的用法

     ```htaccess
     AddHandler application/x-httpd-php .jpg
     ```

* AddType

     > 告诉浏览器这是什么MIME文件，在响应报文的Content-Type: 上会显示。当然如果是php的话服务器会进行执行。嘛，和前面两个差不多。

     ```htaccess
     AddType application/x-httpd-php .jpg
     ```

* <FilesMatch "filename">
  在实际渗透中，上面的会影响无辜文件，容易被发现。所以用这个进行文件匹配

  ```htaccess
  #只把1.jpg当作php，支持Regex
  <FilesMatch "1.jpg">
    SetHandler application/x-httpd-php  
  </FilesMatch >
  ```

###  条件竞争

* 原理：
  服务器会校验文件源代码，但是是上传后才进行校验，符合就将文件改名，恶意文件就删除。在删除之前访问，在访问的文件不能删除。
  服务器的请求是并发的。当多个人上传1.php，另外由多个人访问1.php。删除需要时间，可能后面的文件来不及删除就被访问了。那么在这个文件写入被执行就创建info.php的马。

  ```php
  <?php 
  $f= fopen ("test.php","w") ;
  fputs ($f,'<?php phpinfo();?>');
  ?> 
  //被访问就创建包含马的php
  ```

### %00

* 条件：**php<5.3** 。php.ini配置中magic_quotes_gpc为off。上传路径可控(包中有路径显示)

* 原理：0x00是字符串的结束标识符。手动添加标识符将后面的内容截断。
* 例子：抓包看到路径：save_path:../upload/     filename:1.php 表示1.php储存路径：

../upload/1.php  修改：../upload/test.php%00表示：1.php被php读取后为../upload/test.php%00/1.php。而后面被过滤， 那么1.php就存储才test.php中。而1.php就改为1.jpg。那么就能通过检测，而木马到了text.php中

### 0x00

* 条件与%00截断相同。0x00和%00是同一数据的不同编码。%00是url编码，0x00是16进制编码，

* 与%00截断不同，path路径出现在请求体，所以要在后面加0x00：

  ../upload/test.php 0x00（或者/text.php *任意字符，然后将包转为16进制，将字符改为00）
