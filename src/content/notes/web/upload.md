# 文件上传方案

## 前端直传 OSS

优点：

- 不经过业务服务器，减轻带宽压力
- 支持大文件、高并发

流程：前端向后端申请上传凭证 → 后端签名 → 前端直接上传到 OSS。

## 分片上传

将大文件切成多个分片并行上传，服务端按分片合并。

```js
const chunkSize = 2 * 1024 * 1024; // 2MB
const chunks = Math.ceil(file.size / chunkSize);
```

## 断点续传

记录已上传的分片，中断后从断点继续，适合弱网环境。

## 服务端转发

简单场景下先传到业务服务器，再由服务器转存到对象存储。

## 小结

- 小文件：直传或服务端转发即可
- 大文件：分片 + 断点续传
- 安全：永远不要在前端暴露 AccessKey
