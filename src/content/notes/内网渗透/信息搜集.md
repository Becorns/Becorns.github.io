## COM枚举
```powershell
New-PSDrive -PSProvider registry -Root HKEY_CLASSES_ROOT -Name HKCR
//创建一驱动器，名称为HKCR。将注册表挂在到上面。
Get-ChildItem -Path HKCR:\VCLSID -Name | Select -Skip 1 > clsids.txt
//访问驱动下面的VCLSID，也就是com组件的标识符。
```
有了VCLSID，就能创建com对象，Get-Member查看对象的方法，搜索关键字(execute、exec、run)。获取有用的对象
如搜索ExecuteExcel4Macro，该成员在Microsoft.Office.Interop。那么加载这个com。就能获取ExecuteExcel4Macro函数加载shell32.dll中的 ShellExecuteA。

>COM对象CLSID  093FF999-1EA0-4079-9525-9614C3504B74，可以枚举主机名、用户名、域、网络驱动器等信息
```powershell
 $o = [activator]::CreateInstance([type]::GetTypeFromCLSID("093FF999-1EA0-4079-9525-9614C3504B74")) //获取组件对象

执行： $o 就能获取用户，域，hostname等
```
## 远程登录信息
>PuTTY

PuTTY的连接记录保存在注册表中，HKEY_CURRENT_USER\Software\SimonTatham\PuTTY\SshHostKEys


>Winscp

管理员选择了记住密码，密码会注册表或WinSCP.ini中，使用winscppwd.exe解密* 

>XSHELL&XFTP

XShell 和 XFTP 属于XMangager系列软件。使用Xdecrypt.py 解密XMangager系列软件的密码

> SecureCRT

* 对SecureCRT 7.x及更低版本，可以使用SecureCRTCipher.py对密码进行解密，也可以尝试使用 SecureCRT-decryptpass.py解密
* 对于高版本的SecureCRT，可以把整个%APPDATA%\VanDyke\Config目录复制到本机SecureCRT的Config目录下，然后直接连接
> RDCMan

	Remote DesktopConnection Manager)是一个远程桌面管理工具
* RDCMan可以将连接的远程桌面信息保存为RDG文件。RDG文件记录了目标IP地址、端口号、登录时使用的用户名、经DPAPI加密的密码密文。
* 在目标主机上，可以使用Mimikatz在线解密RDCMan密码。也可以在获取MasterKey后离线解密RDCMan密码
>Navicat

* Navicat的连接凭据存储在注册表中。HKEY_CURRENT_USER\Software\PremiumSoft\Navicat\Servers\<your connectionname>
* 使用 navicat-cipher.py对 Navicat密码进行解密
	python -m pip install cryptography pywin32
	python3 .\navicat-cipher.py dec -v1 A3696E8F53FCA1AE314E7xxx
	
> PL/SQL Developer

PL/SQL Developer凭据保存在user.prefs文件的[LogonHistory]中，凭据的每一行都有一条登录信息。这些信息是加密的，其明文格式为username/password@server。
可以使用java脚本解密

## 文件
> office文件

破解高版本的加密Office文件，可以在目标用户打开文件时使用Sysintermals Suite套件中的工具ProcDump抓取内存dump，然后使用内存查看器（ WinDbg）直接查看文件。
打开加密 Office 文件（Word/Excel，处于打开状态）。
管理员权限运行 CMD/PowerShell。
tasklist | findstr /i "winword excel"
procdump -ma 1348 D:\Dumps\office_full.dmp
-ma：完整内存转储（必须，否则拿不到明文）

对Office文件，可以使用John the Ripper进行破解。
在破解前，要将密码转换成John theRipper支持的hash格式。可以使用office2john.py进行转换
python office2john.py  ..\..\test.docx > ..\..\office.txt
python office2john.py  ..\..\test.xlsx >> ..\..\office.txt
type ..\..\office.txt

使用 John the Ripper 进行破解
john.exe --wordlist=password.lst ..\..\office.txt
john.exe  ..\..\office.txt --show

> 回收站

回收站其实是一个隐藏文件夹。在默认情况下，个人计算机的每个硬盘分区都有对应的回收站（Recycle文件夹，删除文件操作其实是把文件放入这个文件夹）。

```cmd
for %d in (C D E F G H) do @if exist "%d:\$Recycle.Bin" dir /s /b "%d:\$Recycle.Bin\*" 2>nul
# 遍历所有硬盘分区的回收站
```
