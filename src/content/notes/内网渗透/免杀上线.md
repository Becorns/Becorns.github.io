1. 通过virualAlloce 分配一段内存地址

```c
LPVOID VirtualAlloc(
    LPVOID lpAddress,       // 参数1：期望的内存地址，0表示系统自己选
    SIZE_T dwSize,          // 参数2：要分配的大小（字节）
    DWORD  flAllocationType,// 参数3：如何分配
    DWORD  flProtect        // 参数4：内存保护属性
);
flallocationType: 
    MEM_COMMIT	立即分配物理内存，马上就能用
    MEM_RESERVE	只预留地址空间，不分配物理内存，用的时候再提交
    MEM_COMMIT  MEM_RESERVE	先预留再提交（两步合并）
flProtect：//内存保护属性，内存页能干什么
    PAGE_EXCUTE		只执行
    PAGE_READWRITE	读写
    PAGE_WRITE		仅写
```

```c
转换为函数指针
```
