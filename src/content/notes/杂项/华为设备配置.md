### ospf

#### 基础

* ospf在IP报的协议号是89。
* 组播地址224.0.0.5，224.0.0.6
* route-id：
  用来标识ospf中的路由器，多种配置方式，优先顺序：手工->lookback最大的ip->物理接口最大的->0.0.0.0
  修改后需重启

#### 角色

根据优先级选举选举DR/BDR，为0的不参与选举。规则：
优先级大的->route-id大的。

* DR

  指定路由器，

* BDR
  备份路由器

#### 三张表

OSPF邻居邻接表：>display ospf peer 
    OSPF LSDB表：>display ospf lsdb
    OSPF 路由表：>display ip routing-table     或  >display ip routing-table protocol ospf

#### 报文

有五种报文：

* Hello
  组播224.0.0.5，周期性发送，发现，建立(hello时间，区域，RID等)，维持邻居
* DD(Database Description)数据库描述，同步LSA
* LSR(Link State Request)链路状态请求，请求LSA
* LSU(Link State Update)链路状态更新
* LSACK(Link State Acknowledgement) 链路状态回复

#### 邻居过程

1. Down：初始状态，表示没有收到Hello包
2. Attempt：表示没有收到邻居信息，但是已经周期向邻居发送报文，，如果在RouterDeadInterval间隔内没有收到Hello报文，转为Down状态
3. Init：接收到了hell报文，但是对方没有确认包，还没有建立双向通信
4. 2-way：建立双向通信，但是还没有建立邻接关系。选举BR/BDR
5. ExStart：建立邻居的第一步，开始发送DD报文，形成主从关系
6. Exchange：包含链路状态的DD报文，描述本地LSDB内容
7. loading：发送LSR和LSA请求报文，发送LSU通告LSA
8. Full：LSDB同步

## ACL

### 分类

* 基本ACL(2000--2999)
  作用SIP等。方向为out

* 高级ACL(3000-3999)
  sip/dip，sport/dport，方向in

  ```bash
  rule [编号] permit/deny 协议\IP
   source 源IP 反掩码 \
   destination 目的IP 反掩码 \
   [端口条件]
  ```
  
  
  
* 二层ACL(4000-4999)

  源/目的mac，帧类型

* 自定义(5000+)

### 规则

> 两个动作

* permit
* deny

> 两个方向

* inbound
  进路由

* outbound

  出路由

> 匹配规则

* 从上到下，匹配为止
* ARG3有两种
  配置顺序：按照编号匹配
  自动排序：按照精细程度

## STP

> 二层环路会造成广播风暴，mac表震荡，包重复，占用带宽。
> stp/(生成树协议)：有三种：STP，MSTP，RSTP

* 步骤

> 1. 选根桥(负责数据转发)
>
>    根据bid(bridge id,通过dis stp查看)，bid由优先级和mac构成.bid小的为根，mac小的为根.优先级默认是32768，可调整(set priority)，但需为4096的倍数
>
> 2. 每个非根交换机选一个根端口
>    根端口：离根桥最近的端口。选取优先级(路径消耗RPC>对端bid>本端pid)，小的为根端
>
> 3. 每个网段选取指定端口
>    每个链路只有一个，根端口对着的是指定
>    选取(RPC，bid，对端pid，本地pid)

* 相关指令

  ```bash
  stp enable #开启生成树协议
  stp  mode  Mstp/stp/rstp #配置模式
  display stp brief #查看
  dis stp #查看 bid
  stp root primary #修改bid
  stp root primary #直接设置为root，相当于改为0
  stp root secondary #设置为备份根桥
  
  STP：
  Ethernet0/0/4]stp edged-port enable  配置边缘端口（只能针对连接PC终端的接口）
  
  MSTP：
  stp region-configuration #进入区域
  [region] region-name name #设置区域名
  [reg]revision-level 数字 #设置修订号，相当于树/区域的id
  instance 1 vlan 10 
  instance 2 vlan 20 
  active region-configuration 
  [LSW1]stp instance 1 root primary 
  [LSW1]stp instance 2 root secondary
  [LSW3]stp instance 2 root primary 
  [LSW3]stp instance 1 root secondary
  ```

nat-poicy

管理瘦ap，

```bash
#开启dhcp
#配置域模板
wlan
regulaory-domain-profile name default
country-code cn
#建立ap组，应用模板
wlan 
ap-group name office1
regulatory-domain-profile default
ap-group name office2 
regulatory-domain-profile default

#AP加入组
wlan
ap auth-mode mac-auth
ap-id 1 ap-mac {xxxx-xxxx-xxxx}
ap-group office1 #加入组

#ssid模板(构成vap模板):
wlan
ssid-profile name office1
ssid office1
#安全模板(构成vap模板)
wlan 
security-profile naem office1 
security wap-wap2 psk pass-phrase {pass} aes
#vap模板(用于ap组)
wlan 
vap-profile name office1
forward-mod tunnel
service-vlan vlan-id {vlan}
security-profile office1
ssid-profile office1

#ap组中使用vap模板
ap-group name office1
vap-profile office1 wlan 1 radio all

#开启隧道，forward 是tunel隧道模式
capwap source interface Vlanif 100
```
